## Egoera

Makina batek martxa- eta geldialdi-pultsadoreak ditu. Martxa sakatzean, zilindroak aurrera egin behar du eta aurrean geratu, geldialdia sakatu arte. Segurtasunagatik, **geldialdiak lehentasuna** izan behar du.

## Eskakizunak

1. **S1** (martxa, NA) bulkada labur batekin sakatuta, zilindroa ateratzen da eta aurrean geratzen da.
2. **S0** (geldialdia, NI) sakatuta, zilindroa itzultzen da.
3. S0 eta S1 batera sakatuta, zilindroa **ez da** ateratzen.
4. Errele bat erabili behar da, autoatxikimenduarekin.
5. Aukerakoa: pilotu-argi bat (H1), makina martxan dagoenean piztuta.

## Etiketak (derrigorrezkoak)

| Etiketa | Osagaia |
| --- | --- |
| **1A** | Eragin bikoitzeko zilindroa |
| **S1** | Martxa-pultsadorea (NA) |
| **S0** | Geldialdi-pultsadorea (NI) |
| K1 | Errelea (aukerako izena) |
| Y1 | Elektrobalbularen bobina |

## Oharra

Simulazioan, **Shift + klik**-ek pultsadore bat sakatuta uzten du: horrela S0 eta S1 batera proba ditzakezu.
