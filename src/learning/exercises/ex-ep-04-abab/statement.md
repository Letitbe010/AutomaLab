## Egoera

Muntaketa-estazio batean, A zilindroak pieza finkatzen du eta B zilindroak torloju bat sartzen du. Makinak ziklo jarraituan lan egin behar du martxa sakatzen denetik geldialdia sakatu arte.

## Eskakizunak

1. **S1** (martxa) bulkada batekin: **A+ B+ A− B−** zikloa, behin eta berriz.
2. **S0** (geldialdia) sakatzean, une horretako zikloa amaitzen da eta makina hasierako posizioan gelditzen da.
3. Ezer sakatu gabe, makina ez da mugitzen.
4. Mugimendu bakoitza sentsoreek agintzen dute (reed edo amaiera-etengailuak).

## Etiketak (derrigorrezkoak)

| Etiketa | Osagaia |
| --- | --- |
| **1A** | A zilindroa |
| **2A** | B zilindroa |
| **S1** | Martxa-pultsadorea (NA) |
| **S0** | Geldialdi-pultsadorea (NI) |
| 1B1, 1B2, 2B1, 2B2 | Sentsoreak |
| K1 | Zikloaren errelea (aukerako izena) |
| Y1…Y4 | Elektrobalbulen bobinak |

## Gomendatutako urratsak

1. Marraztu espazio-fase diagrama eta idatzi mugimendu bakoitzaren baldintza.
2. Egin martxa/geldialdia autoatxikimenduarekin ([autoatxikimendua](theory:ep-autoatxikimendua)).
3. Gehitu korronte-bide bat mugimendu bakoitzeko.
